ShipGodot automates iOS exporting, code signing, and TestFlight deployment. Build iOS games from Windows, Linux, macOS, or iPad (using Xogot).

> **Note**
> - Requires a paid [Apple Developer Program membership](https://developer.apple.com/programs/enroll/) to work.
> - Requires an active subscription. [Get your license here](https://app.shipgodot.com/checkout/buy/dc482791-e724-40a4-a499-f1c06d8184f6).

## How It Works

Your project is packaged and securely sent to an isolated, temporary macOS virtual machine in our cloud. The server handles export, code signing, and TestFlight deployment. We don't store your project files, they are removed the moment the build finishes.

## Key Features

- **Build From Any Platform**: Export to iOS directly from Linux, Windows, macOS, or iPad.
- **Cloud Offloading**: Free up your local system while our cloud performs the heavy processing.
- **Security First**: Apple signing keys are stored in GitHub's encrypted secrets and pulled in strictly during active builds.
- **Built for Teams**: One license covers all your Godot projects with no seat limits. Share your license with teammates so anyone can ship changes.

## Subscription Details

- Right now we offer one tier 'Indie', which grants you **400 build minutes per month**.

## Known Limitations

- GDScript projects only (C# support in development).
- Direct `.blend` file imports are not yet supported (export to `.gltf` or `.glb` first).
